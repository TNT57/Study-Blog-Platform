# Study Blog Platform

A study blog where students write posts about what they learn and track their focus time with a Pomodoro timer.

This is a learning project. The goal is to practise real Software Engineering skills:
MVC architecture, authentication and authorization, databases (raw SQL, then an ORM),
security (XSS), testing, CI/CD and a design-first workflow.

> Work in progress. The project is built in small milestones, one pull request each.
> Each milestone adds a short learning note in `docs/learn/`.
